FPU numbers match the hardware, not the Verilator sim

The team's Verilator model builds the scalar FP32 FMA with no pipeline registers: fpnew's settings line PipeRegs: '{default: 'd3} fills a packed array, and Verilator puts the 3 only in the last format's slot, so FP32 gets 0. The synthesized Drop 0 netlists do have the 3 stages (DC 269 flops, Yosys-slang 278; checked by Aaron), so this page shows the hardware timing: write at D+4, one FP op per 5 cycles, measured on a Verilator model with that line written row by row. Results are the same either way; only timing differs. Switch to Verilator model to see what the sim shows today (D+1, one per 2). A small fix PR for Reef is planned.
